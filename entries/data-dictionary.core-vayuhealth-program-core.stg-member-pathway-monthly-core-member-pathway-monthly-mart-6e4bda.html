Business definition

Confirmed glycemic pathway at member-month grain (member_cin + reporting_month, plus ecm_enrollment_start_date when present). Historical Google Sheet exports (wide month columns) unpivot into STG for the base load. Later months are snapshotted from MART_Cumulative_Members when you run the cumulative SQL apply for that reporting_month (re-run replaces that month’s pathway slice). VW_Member_Pathway_Month publishes pathway history plus the same default demographics as VW_Member_Month (joined from MART_Cumulative_Members on CIN + enrollment start, else latest episode), so the wide-sheet base does not need demo columns. Tableau MoM charts use pathway_group (A1c / BGM / CGM). This is separate from current computed Pathway on the cumulative book.

Terms used on this page

  • A1c: A blood test that shows a person's average blood sugar over about the last three months. Also written HbA1c. Higher numbers mean less controlled diabetes.
  • BGM: Blood glucose meter: a finger-stick device a member uses to check blood sugar. Sprite may call it SMBGS.
  • CGM: Continuous glucose monitor: a sensor worn on the body that measures blood sugar all day (for example Dexcom or Libre).
  • CIN: Client Index Number: the Medi-Cal member ID. It is PHI. Never type a real one into GitHub.
  • Pathway: How a member's diabetes is tracked: CGM, BGM, or A1c. Based on their devices and recent readings.
  • STG: Staging: the BigQuery layer that holds source files as they arrived, with light cleanup only.
  • Tableau: The dashboard tool Vayu uses for program reporting.
