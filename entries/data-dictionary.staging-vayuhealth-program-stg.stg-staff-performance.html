STG_Staff_Performance

Object Staging (VayuHealth_Program_STG) · STG_Staff_Performance

Business definition

Sprite Staff Performance CSV ({YYYY.MM}_Staff Performance.csv). Loaded into a dedicated table. Does not write STG_Member_Activity_Log. Required: member_cin, activity_date (from activityDate). Maps activityId → id, activityType → touch_type, outreachChannel → outreach_channel. Keeps Vayu Health provider rows when activityPerformedByProvider is present.

The export may be full history (first setup) or one month (ongoing). Each load:

  1. Dedupes the file on Sprite activityId (id)
  2. Deletes existing STG rows whose activity_date month appears in the file
  3. Appends the file
  4. Runs a BigQuery uniqueness pass (one row per id)

So the August bootstrap file replaces Jul 2023–Aug 2026 activity months in one shot; a later September-only file replaces only September and keeps prior history. reporting_month on the row is lineage for the Drive folder month; Tableau months use activity_date in CORE/PROD. source_population = staff_performance. Feeds CORE_Member_Initial_Outreach_Activities → VW_Initial_Outreach_Events.

Terms used on this page

  • BigQuery: Google's cloud database where the pipeline stores its tables.
  • CORE: The BigQuery layer where SQL turns raw source data into business meaning (for example enrollment episodes). CORE objects are views.
  • PROD: The BigQuery layer of approved views. Tableau and Connected Sheets connect only to PROD.
  • Sprite: Sprite Health, Vayu's EHR and care management system. Monthly reports are exported from it.
  • STG: Staging: the BigQuery layer that holds source files as they arrived, with light cleanup only.
  • Tableau: The dashboard tool Vayu uses for program reporting.
