Rule H. Sourcing-list file dashboard (canonical) · Lineage

Business definition

Original CIN rows stay in MART_Sourcing_Received after filtering. STG_Sourcing does not. Months loaded before that received table existed are absent here. Do not rebuild them from current Tracker or Enrolled status.

county file
  → MART_Sourcing_Received   (CIN rows before age / A1c filters; slice replace)
  → STG_Sourcing             (current month only; overwritten next month)
  → CORE_Sourcing_Eligible   (drop enrolled / outreach / declined)
  → MART_Sourcing_Outcome    (frozen flags for that receipt month)
  → PROD_Sourcing            (current outreach list; city filter)
  → three county Google Sheets (Connected Sheets on PROD_Sourcing)
  → Outreach_Sourcing_List_Updates
  → PROD_Sourcing_File_Dashboard (this view; does not write those objects)

Terms used on this page

  • A1c: A blood test that shows a person's average blood sugar over about the last three months. Also written HbA1c. Higher numbers mean less controlled diabetes.
  • CIN: Client Index Number: the Medi-Cal member ID. It is PHI. Never type a real one into GitHub.
