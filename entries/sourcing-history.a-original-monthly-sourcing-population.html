A. Original monthly sourcing population

Rule A. Original monthly sourcing population

In plain terms

Everyone who appeared on a county sourcing list each month, counted before any age or clinical filters.

Business definition

Python writes MART_Sourcing_Received from each source file before age or clinical filters:

  • Stanislaus Cozeva HbA1c → source_name = stanislaus_cozeva_hba1c
  • Stanislaus Cozeva Demographics → source_name = stanislaus_cozeva_demographics
  • Shasta A1C_GT8 → source_name = shasta_a1c_gt8
  • Humboldt PHC DM A1C9+ → source_name = humboldt_phc_dm_a1c

Each row keeps county, sourcing month (first of month), source file name, source row number, CIN, DOB, age as of that month, A1c value/date, last admission date, pipeline run id, and ingested_at.

A member who appears again next month is a new received row for that month. Rerunning the same month + county + source replaces that slice. It does not append.

Replacement files: drop the corrected file in the same Drive folder and rerun that month. The slice replace overwrites the previous received rows for that source. Do not load two versions of the same month side by side.

Count labels:

Do not label the sum of monthly distinct counts as unique members ever received. That number is the all_months grain on VW_Sourcing_Funnel.

Terms used on this page

  • A1c: A blood test that shows a person's average blood sugar over about the last three months. Also written HbA1c. Higher numbers mean less controlled diabetes.
  • CIN: Client Index Number: the Medi-Cal member ID. It is PHI. Never type a real one into GitHub.
  • Cozeva: The health plan quality platform that Stanislaus County member lists come from.
  • HbA1c: Same as A1c.
  • PHC: Partnership HealthPlan of California, the health plan for Humboldt and Shasta counties.
