Data Dictionary / Enrollment and membership

CORE_Member_MIF

Object Core (VayuHealth_Program_CORE) · CORE_Member_MIF

Business definition

One row per member_cin: first/last MIF dates, PCP, risk fields, MIF adult population-of-focus Yes/No flags from the latest MIF, plus discontinuation_reason and discontinuation_reason_code from that same MIF row. Does not publish pof.

Terms used on this page

  • MIF: Member Information File: the ECM file shared with the health plan. It holds discontinuation reasons and population-of-focus flags.
