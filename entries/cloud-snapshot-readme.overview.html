Reference Overview

In plain terms

The Tableau calculations behind four dashboards, each with a draft plain-English definition (added 2026-11-20) waiting for the data lead's approval. Notes marked Check before approving point out formulas that may count the wrong people or give a wrong number.

Business definition

This folder records calculated fields from one Tableau Cloud Metadata API page that were missing, by exact name, from ../member_month_kpis.md.

The member-month file is unchanged and remains the documented formula when a name already exists there. Formulas that use the same name with different text are compared in ../reconciliation/2026-10-21-tableau-metadata.md. They are not copied over the existing definitions.

The request named Vayu Health Phase 1 (Enrollment) DBe. The snapshot workbook name is Vayu Health Phase 1 (Enrollment) DB. These files use the snapshot spelling.

The page did not include calculation ids or data-source ids. pageInfo.hasNextPage was true. Downstream workbook names are lineage on each row, not a complete membership list. pending review.

Terms used on this page

  • Cumulative Members: The permanent list of every Vayu enrollment episode, kept in MART_Cumulative_Members.

  • View: A saved database query that always shows current data. Unlike a table, it stores no rows of its own.
