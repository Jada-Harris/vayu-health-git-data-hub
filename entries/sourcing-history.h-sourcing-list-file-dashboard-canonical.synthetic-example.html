Rule H. Sourcing-list file dashboard (canonical) · Synthetic example

Business definition

One Shasta file, receipt month 2026-09, four distinct CINs: A age 17, B blank A1c, C numeric A1c and a valid outreach date, D numeric A1c and no outreach date. No second copy of any CIN. Outcome snapshot exists and C and D are not enrolled, in outreach, declined, or out of area.

Terms used on this page

  • A1c: A blood test that shows a person's average blood sugar over about the last three months. Also written HbA1c. Higher numbers mean less controlled diabetes.
  • CIN: Client Index Number: the Medi-Cal member ID. It is PHI. Never type a real one into GitHub.
