ECM activities (CORE_Member_ECM_Activities)

Metric Member-month (program membership + service) · ECM / ECM+ event eligibility (CORE)

Business definition

Activity date is inside a CORE_Member_Enrollments episode; episode end = COALESCE(ecm_enrollment_end_date, discontinuation_date). Null enrollment start and out-of-window rows are dropped (not zero-flagged).

Inclusion criteria
