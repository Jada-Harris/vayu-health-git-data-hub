Data Dictionary / Clinical outcomes

VW_Clinical_Outcome_MoM

Object Core (VayuHealth_Program_CORE) · VW_Clinical_Outcome_MoM

Business definition

Additive Tableau PROD view. One row per member_cin + reporting_month from VW_Member_Month, with A1c / PHQ-9 / GAD-7 / DDS recomputed as-of that month’s end from CORE_Member_Measurements (same score rules as CORE_Member_Clinical_Outcomes, time-capped). Includes member-month demographics for filters, *_as_of carryforward scores for run charts, deltas, missing/has flags, and existing improvement thresholds. Does not write MART or change the cumulative book. Apply: python/apply_clinical_outcome_mom_sql_models.py.

Terms used on this page

  • A1c: A blood test that shows a person's average blood sugar over about the last three months. Also written HbA1c. Higher numbers mean less controlled diabetes.
  • DDS: Diabetes Distress Scale: a short survey about how stressful living with diabetes feels.
  • GAD-7: A 7-question anxiety screening survey.
  • MART: The BigQuery layer of analysis-ready tables, such as one row per member or per member per month.
  • PHQ-9: A 9-question depression screening survey.
  • PROD: The BigQuery layer of approved views. Tableau and Connected Sheets connect only to PROD.
  • Tableau: The dashboard tool Vayu uses for program reporting.
