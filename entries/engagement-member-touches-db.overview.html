Engagement (Member Touches) DB calculated fields from Tableau Cloud

Reference Overview

Business definition

Workbook name in the snapshot: Vayu Health Engagement (Member Touches) DB.

These formulas were on the Tableau Cloud Metadata API page supplied on 21 Oct 2026 and were absent, by exact calculation name, from docs/tableau/member_month_kpis.md. That file remains the copy-paste source for the member-month KPIs already documented there. Nothing in this file replaces those definitions.

Each block below is the original calculated-field formula. Calculation ids and data-source ids were not in the payload. A downstream workbook is lineage returned for that row, not ownership, and it does not show that every copy of the calculation was returned. pageInfo.hasNextPage was true, so this file is a snapshot inventory, not a complete workbook export. Owner, approval date, and validation status are not stated in the snapshot. Each calculation below has a draft plain-language definition written on 2026-11-20 from its formula. A draft stays marked pending review until the data lead approves it: change its Approval status line to Approved by <name>, <date> and remove the Check before approving note once it is answered.

SQL and pipeline rules stay in docs/metric_definitions.md. They are not copied here as Tableau formulas.
