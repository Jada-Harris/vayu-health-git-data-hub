Data Dictionary / Data tables and reference

Data dictionary

Reference Overview

Business definition

STG and MART objects are tables. CORE and PROD objects are views.

Enrollment key in CORE/MART member models: member_cin + ecm_enrollment_start_date. Member-month grain is member_cin + reporting_month. Keep member_cin as text end-to-end — CINs that contain the letter E (e.g. 9XXXXXXXE2) become Excel floats like 9.63E+09 if opened as numbers, which creates a duplicate No-service member-month row beside the real CIN. The pipeline runbook has the repair steps.

Terms used on this page

  • CIN: Client Index Number: the Medi-Cal member ID. It is PHI. Never type a real one into GitHub.
  • CORE: The BigQuery layer where SQL turns raw source data into business meaning (for example enrollment episodes). CORE objects are views.
  • MART: The BigQuery layer of analysis-ready tables, such as one row per member or per member per month.
  • Member-month: One row for each member for each month they were in the program. Used to count members and services by month.
  • PROD: The BigQuery layer of approved views. Tableau and Connected Sheets connect only to PROD.
  • STG: Staging: the BigQuery layer that holds source files as they arrived, with light cleanup only.
