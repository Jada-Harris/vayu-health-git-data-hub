Phases (Activity Log only)

Metric Phases (Activity Log only)

In plain terms

The start date and length of each program phase (1 to 4), based on specific activities logged in Sprite.

Business definition

Requires member_cin, activity_date, and description. Filter: accountable_provider = Vayu Health.

as_of = reporting-month end (BigQuery) / script run date (Colab).

Once Phase 1–4 dates/days are filled on MART / master, monthly runs do not overwrite them (fill blank only).

Negative phase days are flagged in QA, not rewritten.

Terms used on this page

  • BigQuery: Google's cloud database where the pipeline stores its tables.
  • Colab: Google Colaboratory: the browser notebooks in notebooks/ that run the monthly pipeline.
  • MART: The BigQuery layer of analysis-ready tables, such as one row per member or per member per month.
  • Sprite: Sprite Health, Vayu's EHR and care management system. Monthly reports are exported from it.
