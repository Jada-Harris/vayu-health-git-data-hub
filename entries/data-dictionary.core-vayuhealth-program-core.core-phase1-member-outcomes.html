Business definition

Additive lifecycle view. Grain is one row per enrollment episode (member_cin + enrollment start) plus one OUTREACH row per never-enrolled member. Reuses first-outreach activity from CORE_Member_Initial_Outreach_Activities, enrolled episodes from MART_Cumulative_Members, and outreach / recent enrollment fallback from CORE_ECM_Tracker_Members. The view resolves historical cumulative MART column names such as membercin as well as canonical names such as member_cin; it does not rename or alter the MART table.

Key fields:

For a first enrollment episode, qualifying outreach is on or before the ECM start. For a re-enrollment episode, qualifying outreach must be after the previous episode end and on or before the new ECM start. Counts and first outreach dates are therefore episode-specific and are not copied across a member's enrollment episodes.

region on this view, and on the other outreach views, is grouped: Humboldt and Sierra (any capitalization) become Humboldt; Shasta, Tehama, and Trinity are each folded to one title-case label. Other region text is left as exported. The grouping is applied after cumulative, Tracker, and outreach region are coalesced, so a mixed-case value from the book or Tracker still lands in the grouped label.

The CORE view retains discontinuation_reason_code and discontinuation_reason_source_text for lineage. The PROD view publishes only discontinuation_reason. A numeric source code is mapped first, so code 1 always becomes The Member has met all care plan goals even if the free-text reason field says something else. An unknown numeric code is published as Unmapped discontinuation reason for visible QA rather than as a number.
