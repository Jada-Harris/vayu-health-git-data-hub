CORE_ECM_Tracker_Members

Object Core (VayuHealth_Program_CORE) · CORE_ECM_Tracker_Members

Business definition

One row per Tracker CIN (member_client_index_number → member_cin). Maps Tracker snake_case fields to program demo names (member_ecm_status → workflow_status, ecm_lead_care_manager_* → care coordinator fields, benefit dates → enrollment dates). Priority 3 in PROD demos coalesce.

Terms used on this page

  • CIN: Client Index Number: the Medi-Cal member ID. It is PHI. Never type a real one into GitHub.
  • PROD: The BigQuery layer of approved views. Tableau and Connected Sheets connect only to PROD.
