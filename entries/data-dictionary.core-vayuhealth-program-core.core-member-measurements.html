Data Dictionary / Clinical outcomes

CORE_Member_Measurements

Object Core (VayuHealth_Program_CORE) · CORE_Member_Measurements

Business definition

Long measurements with standard_marker in HbA1c, GMI_1_Month, PHQ_9, DDS, GAD_7, PAM_Level, PAM_Score, Glucose, Mean Plasma Glucose, Blood Sugar Fasting Marker, Blood Sugar Before Meal. Incomplete PAM Level/Score pairs on the same CIN + date are dropped. Glucose markers are pathway-only.

Terms used on this page

  • CIN: Client Index Number: the Medi-Cal member ID. It is PHI. Never type a real one into GitHub.
  • DDS: Diabetes Distress Scale: a short survey about how stressful living with diabetes feels.
  • HbA1c: Same as A1c.
  • PAM: Patient Activation Measure: a 13-question survey (scored 0 to 100, levels 1 to 4) about how ready a person is to manage their own health.
