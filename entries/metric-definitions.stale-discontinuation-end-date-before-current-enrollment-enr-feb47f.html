Data Dictionary / Enrollment and membership

Stale discontinuation / end date before current enrollment (Enrolled)

Metric Stale discontinuation / end date before current enrollment (Enrolled)

In plain terms

If a currently enrolled member still shows an exit date from an earlier program that falls before their current start date, that old exit date is ignored.

Business definition

Sprite Demographics sometimes carries another program's prior exit onto a member who is Enrolled in our program with a later ecm_enrollment_start_date.

Rule (pandas workbook and BigQuery CORE → Incoming → MART MERGE):

  1. Member is on the Enrolled Members file (source_population = enrolled / enrolled roster)
  2. workflow_status = Enrolled
  3. ecm_enrollment_start_date is populated
  4. discontinuation_date or ecm_enrollment_end_date is populated and is strictly before that start date

→ Null that stale date. When discontinuation_date is cleared, also clear discontinuation_reason / discontinuation_reason_code.

Example: Enrolled in October 2026 with start in 2026, but Demographics still shows a April 2026 discontinuation from another program → null the April date.

For Enrolled rows, monthly MERGE accepts Incoming NULL on discontinuation_date / ecm_enrollment_end_date so a cleaned Incoming value can clear a locked historical MART date. Non-enrolled rows keep fill-blank behavior for those exit dates.

Terms used on this page

  • BigQuery: Google's cloud database where the pipeline stores its tables.
  • CORE: The BigQuery layer where SQL turns raw source data into business meaning (for example enrollment episodes). CORE objects are views.
  • MART: The BigQuery layer of analysis-ready tables, such as one row per member or per member per month.
  • MERGE: A database step that updates rows that already exist and adds rows that are new, without duplicating them.
  • Sprite: Sprite Health, Vayu's EHR and care management system. Monthly reports are exported from it.
