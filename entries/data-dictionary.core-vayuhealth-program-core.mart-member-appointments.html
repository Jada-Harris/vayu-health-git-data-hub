Data Dictionary / Appointments and visits

MART_Member_Appointments

Object Core (VayuHealth_Program_CORE) · MART_Member_Appointments

Business definition

Same appointment grain as CORE. Left join to CORE_CareTeam_Staff_Roster on the lowercased, whitespace-normalized specialist name. is_valid_chw_specialist is true when the matched row has ecm_staff_type = 'CHW'. The roster has no effective dates.

Demographics are one row per member_cin: latest MART_Cumulative_Members episode, then CORE_ECMPlus_Member_Demos, then CORE_ECM_Tracker_Members. A missing demographic row does not drop the appointment. health_plan is organization.

Terms used on this page

  • CORE: The BigQuery layer where SQL turns raw source data into business meaning (for example enrollment episodes). CORE objects are views.
