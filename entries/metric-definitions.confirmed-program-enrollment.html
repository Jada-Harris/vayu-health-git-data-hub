Data Dictionary / Enrollment and membership

Confirmed program enrollment

Metric Confirmed program enrollment

In plain terms

A member counts as enrolled in the program only when they have an ECM enrollment start date and belong to one of the four program care teams (Sequoia, Redwoods, Mariposa, or Sundial).

Business definition

A demographics row is a program enrollment episode only when both are true:

  • ecm_enrollment_start_date is not null
  • care_coordinator_team is Sequoia Team, Redwoods Team, Mariposa Team, or Sundial Team (spacing and case ignored)

The team test uses the team already stored on MART_Cumulative_Members for that (member_cin, ecm_enrollment_start_date) when one exists. Otherwise it uses the current Demographics value. Outreach Team and any other team are not program enrollments.

Once care_coordinator_team is stored for an episode, monthly MERGE does not change it. Correct a wrong stored team on the MART row directly.

Terms used on this page

  • ECM: Enhanced Care Management: the Medi-Cal (CalAIM) benefit that pays Vayu to coordinate care for members with complex needs.
  • MART: The BigQuery layer of analysis-ready tables, such as one row per member or per member per month.
  • MERGE: A database step that updates rows that already exist and adds rows that are new, without duplicating them.
