Data Dictionary / Sourcing and eligibility

excluded_previously_received

Rule H. Sourcing-list file dashboard (canonical) · First exclusion reason

In plain terms

Already on an earlier list for the same county (lists from November 2026 on).

Business definition

last, and only when receipt_month is 2026-11-01 or later. Same county and same CIN on an earlier membership file (stanislaus_cozeva_demographics, shasta_a1c_gt8, or humboldt_phc_dm_a1c). HbA1c-only rows do not count. An earlier reason still wins, so a member who is also already in outreach stays in that bucket. The member can still have previously_received_flag = 1. Months before November 2026 do not use this reason, including when those months are rebuilt. The CIN stays in MART_Sourcing_Received. Order: 7

Terms used on this page

  • CIN: Client Index Number: the Medi-Cal member ID. It is PHI. Never type a real one into GitHub.
  • HbA1c: Same as A1c.
