Validation

Rule Validation

Business definition

History checks:

  • received rows still exist after filtering
  • reruns replace a month/source slice instead of appending (operational: rerun and confirm received row count matches the file, not 2×)
  • remaining matches MART_Sourcing_Member_Month
  • ever-received ≤ sum of monthly distinct
  • one attributed cohort per member
  • enrolled conversion never invents outreach

Member-view checks:

  • one row per county + sourcing month + CIN
  • Stanislaus HbA1c-only CINs are not received rows
  • Stanislaus A1c matches the single paired HbA1c file; unpaired runs stay null
  • verification status flags are exclusive
  • declined, already-in-outreach, and out-of-area flags match the outcome booleans
  • name / DOB / phone / address / PCP / notes columns are absent

Terms used on this page

  • A1c: A blood test that shows a person's average blood sugar over about the last three months. Also written HbA1c. Higher numbers mean less controlled diabetes.
  • CIN: Client Index Number: the Medi-Cal member ID. It is PHI. Never type a real one into GitHub.
  • HbA1c: Same as A1c.
