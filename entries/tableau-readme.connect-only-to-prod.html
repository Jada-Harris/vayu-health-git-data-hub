Business definition

PRAPARE views omit pregnancy/postpartum, EPDS, comments, and infant-care fields (those stay in STG).

Phase 1 outcomes: all program exits (graduates + other discharges) use exit_group = Program exit or is_program_exit. Discharged members use is_program_discharge and do not include graduates. Graduations use is_graduated. Source code 1 maps to The Member has met all care plan goals. Calendar-month unique outreached and attempts stay on VW_Initial_Outreach_Events. Members added to outreach use member_created_date / added_to_outreach_month on VW_Phase1_Member_Outcomes.

Monthly outreach conversion uses reporting_month for every graph on this source. Denominator = COUNTD of member_cin where outreached_in_reporting_month. Same-month numerator = enrolled_in_reporting_month. Overall numerator = enrolled_in_month, which includes an enrollment after outreach in an earlier month. Members added to outreach = COUNTD of member_cin where added_to_outreach_in_reporting_month. Do not use COUNTD([member_cin]) as the denominator, and do not sum row counts across channels. An outreach_channel filter leaves out members who were added and never outreached, because that channel is blank.

Outreach region on the outreach views is already grouped: Humboldt and Sierra (any capitalization) are Humboldt; Shasta, Tehama, and Trinity are each one title-case label. Other region text is left as exported. Do not add a Tableau group on top of that.

Do not point Tableau at STG, CORE, or MART.
