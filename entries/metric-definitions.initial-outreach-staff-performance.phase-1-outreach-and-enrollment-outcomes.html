Data Dictionary / Outreach and enrollment conversion

Phase 1 outreach and enrollment outcomes

Metric Initial outreach (Staff Performance) · Phase 1 outreach and enrollment outcomes

In plain terms

For each enrollment, how many outreach attempts it took and how many days passed from first outreach to enrollment, plus how members later left the program.

Business definition

Tableau member-outcome source: VayuHealth_Program_PROD.VW_Phase1_Member_Outcomes.

is_program_discharge does not include graduates. Use is_program_exit or exit_group = Program exit for the combined program-exit chart, then is_graduated or member_outcome_category = Graduated for the graduation slice.

member_outcome_category is mutually exclusive and uses this order: Graduated, Discharged from Program, Discontinued from Outreach. It is null when none of those outcomes applies.

Outreach after an episode starts is not assigned backward to that episode. Rows without qualifying pre-enrollment outreach have a null days_from_first_outreach_to_enrollment.

VW_Phase1_Member_Outcomes.discontinuation_reason contains text only. Approved ECM Tracker mappings:

  • 1: The Member has met all care plan goals
  • 2: The Member is ready to transition to a lower level of care
  • 3: The Member no longer wishes to receive ECM
  • 4: The ECM Provider has not been able to connect with the Member after multiple attempts
  • 5: Incarcerated
  • 6: Declined to participate
  • 7: Duplicative program
  • 8: Lost Medi-Cal coverage
  • 9: Switched health plans
  • 10: Moved out of the county
  • 12: Unsafe behavior or environment
  • 14: Deceased
  • 15: Other

Raw code fields remain CORE-only.

Terms used on this page

  • CORE: The BigQuery layer where SQL turns raw source data into business meaning (for example enrollment episodes). CORE objects are views.
  • ECM: Enhanced Care Management: the Medi-Cal (CalAIM) benefit that pays Vayu to coordinate care for members with complex needs.
  • ECM Tracker: The Sprite report that lists members in outreach and enrollment, with their status and dates.
  • Tableau: The dashboard tool Vayu uses for program reporting.
