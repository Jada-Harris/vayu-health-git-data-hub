Data Dictionary / Clinical outcomes

VW_Clinical_Outcome_MoM

Object Core (VayuHealth_Program_CORE) · VW_Clinical_Outcome_MoM

Business definition

Additive Tableau PROD view. One row per member_cin + reporting_month from VW_Member_Month. Score picks match the cumulative book / CORE_Member_Clinical_Outcomes (closest A1c/GMI baseline — GMI alone counts, earliest-after-day-180 then lower for 6-month, episode most-recent; behavioral closest on/after else before), recomputed as-of month end from CORE_Member_Measurements, with fallback to locked MART_Cumulative_Members A1c/GMI fields when measurements yield null. MoM layer: baselines lock once and backfill earlier months; 6-month progresses with earlier-month backfill; hba1c_gmi_as_of = COALESCE(most_recent, 6-month, baseline). Includes member-month demographics, deltas, missing/has flags, and improvement thresholds. Does not write MART or change the cumulative book. Apply: python/apply_clinical_outcome_mom_sql_models.py.

Terms used on this page

  • A1c: A blood test that shows a person's average blood sugar over about the last three months. Also written HbA1c. Higher numbers mean less controlled diabetes.
  • GMI: Glucose Management Indicator: an estimate of A1c calculated from CGM readings.
  • MART: The BigQuery layer of analysis-ready tables, such as one row per member or per member per month.
  • PROD: The BigQuery layer of approved views. Tableau and Connected Sheets connect only to PROD.
  • Tableau: The dashboard tool Vayu uses for program reporting.
