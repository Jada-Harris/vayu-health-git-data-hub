Data Dictionary / Sourcing and eligibility

First exclusion reason

Rule H. Sourcing-list file dashboard (canonical) · First exclusion reason

In plain terms

The main reason a member on a sourcing list was not added to outreach. Reasons are checked in the order below, and only the first one that applies is recorded.

Business definition

Coded order (loader, then outcome SQL). Dashboard column order is not the priority.

Service-area cities match PROD_Sourcing (Stockton, Corcoran, Hilmar, Fairfield, Mariposa, Escalon, Eugene, Manteca, Sunnyvale, Merced, Delhi, Farmington, Burney, Fall River Mills, and Del Norte). City is not on the received snapshot, so this reason exists only on the outcome snapshot.

members_without_exclusion_reason holds everyone else, including people still pending and people whose program status was never snapshotted. Distinct members equal the non-null first-reason counts plus that remainder. Inapplicable NULL buckets are not extra people.
