Data Dictionary / Enrollment and membership

CORE_Member_Enrollments

Object Core (VayuHealth_Program_CORE) · CORE_Member_Enrollments

Business definition

One row per (member_cin, ecm_enrollment_start_date) from shared STG_Member_Demographics. A row is kept only when the start date is present and care_coordinator_team is Sequoia Team, Redwoods Team, Mariposa Team, or Sundial Team. The stored MART team is used for that test when the episode is already on the book. Enrolled rows are the demographic base; discontinued rows overlay workflow_status and end/discontinuation date fields. Disc-only episodes are retained when they pass the team test. No pathway / A1c / phase / touch flags. Does not publish discontinuation_reason / discontinuation_reason_code (those come from MIF). Does not compute dm_type / direct_referral / enrollment_number. pof remains the Demographics column.

Terms used on this page

  • A1c: A blood test that shows a person's average blood sugar over about the last three months. Also written HbA1c. Higher numbers mean less controlled diabetes.
  • MART: The BigQuery layer of analysis-ready tables, such as one row per member or per member per month.
  • MIF: Member Information File: the ECM file shared with the health plan. It holds discontinuation reasons and population-of-focus flags.
