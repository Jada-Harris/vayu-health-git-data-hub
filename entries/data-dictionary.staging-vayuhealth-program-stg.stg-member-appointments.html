Data Dictionary / Appointments and visits

STG_Member_Appointments

Object Staging (VayuHealth_Program_STG) · STG_Member_Appointments

Business definition

Loaded from the Appointments sheet on Enrolled and/or Discontinued Pop Builder workbooks. Same month-slice replace as the other STG tables. Feeds CORE_Member_Appointments. This is the recurring appointments source. MIG_Tableau_Appointments is a one-time historical lander and is not the monthly upstream.

Sprite columns are kept under snake_case names (specialist_name, service_name, vendor_name, start_time, id, and the rest of the sheet). start_time is stored as text so an invalid clock value does not fail the load and so the time is not truncated to a date. appointment_date stays a date when the sheet has a separate date column.

Appointments keep a row when vendor_name and provider are Vayu Health or blank. Any other populated vendor or provider (including New Life Discovery Project, Inc.) is dropped at load. SQL repeats that allow-list.

Terms used on this page

  • Pop Builder: Population Builder, the Sprite report tool used for the Enrolled Members and Discontinuations exports.
  • Sprite: Sprite Health, Vayu's EHR and care management system. Monthly reports are exported from it.
  • STG: Staging: the BigQuery layer that holds source files as they arrived, with light cleanup only.
