Data Dictionary / Sourcing and eligibility

Grain

Rule I. Sourcing members reporting view · Grain

Business definition

One row per county + sourcing_month + member_cin on the membership file:

HbA1c-only CINs are not rows. Duplicate membership-file CINs collapse to one row (duplicate_cin_on_membership_file is true when the file had more than one).

Stanislaus last_test_result and last_test_date come from the paired stanislaus_cozeva_hba1c row: same county, sourcing month, pipeline_run_id, and CIN, and only when that run has exactly one HbA1c filename. The HbA1c file is collapsed to one row per CIN before the join. A blank run id, or more than one HbA1c filename on the run, leaves the result null. Shasta and Humboldt keep the result stored on the membership file. A1c under 9 is not a flag.

Terms used on this page

  • A1c: A blood test that shows a person's average blood sugar over about the last three months. Also written HbA1c. Higher numbers mean less controlled diabetes.
  • CIN: Client Index Number: the Medi-Cal member ID. It is PHI. Never type a real one into GitHub.
  • Grain: What one row in a table stands for, for example one member per month.
  • HbA1c: Same as A1c.
