Sheet yes/no dictionary

Rule I. Sourcing members reporting view · Sheet yes/no dictionary

Business definition

Apps Script stores unconstrained STRING values. Flags use this token list after LOWER(TRIM(...)):

Blank verified_eligible → pending_verification_flag = 1 and verification_status = pending. Any other non-blank token is verification_status = unmapped and sheet_value_unmapped_flag = 1. It is not counted as eligible, not eligible, or pending. Review those rows before trusting scorecards.

dm_type_populated_flag is 1 when dm_type is non-blank. It is not a yes/no field.

Terms used on this page
