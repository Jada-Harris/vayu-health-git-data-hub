Business definition

A demographics row is a program enrollment episode only when both are true:

  • ecm_enrollment_start_date is not null
  • care_coordinator_team is Sequoia Team, Redwoods Team, Mariposa Team, or Sundial Team (spacing and case ignored)

The team test uses the team already stored on MART_Cumulative_Members for that (member_cin, ecm_enrollment_start_date) when one exists. Otherwise it uses the current Demographics value. Outreach Team and any other team are not program enrollments.

Once care_coordinator_team is stored for an episode, monthly MERGE does not change it. Correct a wrong stored team on the MART row directly.
