Data Dictionary / Clinical outcomes

Flourish enrollment / MoM distribution (A1c-style)

Metric Flourish PAM · Flourish enrollment / MoM distribution (A1c-style)

Business definition

Separate from Trend pairing. Source: Flourish assessments, all survey series pooled per CIN.

  • Baseline: closest valid completion before ECM enrollment start.
  • Most recent: latest valid completion on/after day 180 and within the enrollment episode (MoM view also caps at month end).
  • Distribution charts / run charts: use distribution_pam_level / distribution_pam_score = most recent if present, else baseline carryforward.
  • Avg score increase on these views: only where has_post_180_day_pam (do not treat carryforward rows as zero change).

Tableau sources: VW_PAM_Enrollment_Outcomes, VW_PAM_MoM_Run_Chart.

Terms used on this page

  • A1c: A blood test that shows a person's average blood sugar over about the last three months. Also written HbA1c. Higher numbers mean less controlled diabetes.
  • Baseline: A member's first relevant measurement for an enrollment, picked as the one closest to the enrollment start date. Used to measure change over time.
  • CIN: Client Index Number: the Medi-Cal member ID. It is PHI. Never type a real one into GitHub.
  • ECM: Enhanced Care Management: the Medi-Cal (CalAIM) benefit that pays Vayu to coordinate care for members with complex needs.
  • Flourish: The vendor platform where members complete the PAM survey.
  • Tableau: The dashboard tool Vayu uses for program reporting.
