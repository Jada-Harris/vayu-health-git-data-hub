Stable entry ID

data-dictionary.core-vayuhealth-program-core.core-member-pathway

Business definition

One row per (member_cin, ecm_enrollment_start_date): member_name and workflow_status from MART_Cumulative_Members (legacy membername / workflowstatus when the normalized column is blank; current enrollment fills a still-blank value), device flags, 60-day measurement flags, cgm_type, bgm_type, and a single pathway label. The first matching rule wins: (1) Active CGM + recent GMI = CGM Active; (2) Active CGM + no recent GMI = Possible CGM Malfunction; (3) No active CGM + recent GMI = Possible CGM Malfunction; (4) Active BGM + recent glucose = BGM Active; (5) Active BGM + no recent glucose = Possible BGM Malfunction; (6) No active BGM + recent glucose = Possible BGM Malfunction; (7) everything else enrolled = A1c; (8) not enrolled = blank. No active device includes an inactive device and no device of that type. A recent measurement with no matching active device is a malfunction.
