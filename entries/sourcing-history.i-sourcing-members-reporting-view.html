I. Sourcing members reporting view

Rule I. Sourcing members reporting view

In plain terms

One row per member on each county membership file, with Yes/No flags for each outreach step. It feeds the Looker Studio sourcing dashboard and holds no contact details.

Business definition

Looker Studio / Tableau object: VayuHealth_Sourcing_Data.VW_Sourcing_Members.

This is the member-level operational dashboard. It does not replace PROD_Sourcing (Sheets worklist) or PROD_Sourcing_File_Dashboard (batch grain). Conversion reporting stays on VW_Sourcing_Funnel / VW_Sourcing_Cohort_Member.

Terms used on this page

  • Looker Studio: Google's dashboard tool. The sourcing dashboards are built there.
  • Tableau: The dashboard tool Vayu uses for program reporting.
