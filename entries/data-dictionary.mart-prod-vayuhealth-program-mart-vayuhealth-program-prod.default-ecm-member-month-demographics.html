Data Dictionary / ECM and ECM+ services

Default ECM member-month demographics

Object Mart / Prod (VayuHealth_Program_MART, VayuHealth_Program_PROD) · Default ECM member-month demographics

Business definition

Canonical columns for ECM / ECM+ member-month reporting (MART_Monthly_Members_Serviced → VW_Member_Month). Primary source is MART_Cumulative_Members (pipeline snake_case or historical Tableau MIG collapsed names). Blanks fill from ECM+ encounter demos, then ECM Tracker.

MART_Monthly_ECM_ECMPlus_Events is the event-grain replacement for VayuHealth_Program_Data.ECM_and_ECMplus.

VW_Member_Month exposes category, counts, Yes/No flags (ecm_billed_touches_flag, bh_encounter_flag, rd_encounter_flag, ecmplus_encounter_flag, both_bh_and_rd_flag, no_service_in_the_month), active membership Yes/No flags, and the default demographics list above; drops Outreach Team only. Tableau health_plan is demographics organization. reporting_month stays YYYY-MM text. reporting_month_date is that month's first day (DATE) for discrete month charts. HUMBOLDT and SHASTA are published as Humboldt and Shasta; other county values are unchanged. Active membership trend charts should filter active_during_month = Yes or active_at_month_end = Yes by reporting_month_date.

VW_ECM_ECMPlus_Events exposes event facts plus the same default demographics (joined from MART_Monthly_Members_Serviced on member_cin + reporting_month). Tableau health_plan: ECM+ encounters use encounter mcp_name (fallback to demographics organization); ECM activity rows use demographics organization.

Terms used on this page

  • ECM: Enhanced Care Management: the Medi-Cal (CalAIM) benefit that pays Vayu to coordinate care for members with complex needs.
  • ECM Tracker: The Sprite report that lists members in outreach and enrollment, with their status and dates.
  • ECM+: Vayu's extra clinical services on top of ECM: billed visits with behavioral health (BH) clinicians or dietitian and diabetes educators (RDCDCES).
  • Tableau: The dashboard tool Vayu uses for program reporting.
