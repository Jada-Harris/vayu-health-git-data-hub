Data Dictionary / Clinical outcomes

Behavioral screens

Metric Behavioral screens

In plain terms

How the starting and most recent PHQ-9 (depression), DDS (diabetes distress), GAD-7 (anxiety), and PAM scores are chosen for each enrollment.

Business definition

Markers: PHQ_9, DDS, GAD_7, PAM_Level, PAM_Score.

Baseline: closest record on/after enrollment; if none, closest record before enrollment. PAM Level uses text when present.

Most recent: latest record after the baseline date and on/before episode end.

PAM Level and PAM Score must both exist on the same CIN + date; incomplete pairs are dropped in CORE measurements.

Terms used on this page

  • Baseline: A member's first relevant measurement for an enrollment, picked as the one closest to the enrollment start date. Used to measure change over time.
  • CIN: Client Index Number: the Medi-Cal member ID. It is PHI. Never type a real one into GitHub.
  • CORE: The BigQuery layer where SQL turns raw source data into business meaning (for example enrollment episodes). CORE objects are views.
  • DDS: Diabetes Distress Scale: a short survey about how stressful living with diabetes feels.
  • GAD-7: A 7-question anxiety screening survey.
  • PAM: Patient Activation Measure: a 13-question survey (scored 0 to 100, levels 1 to 4) about how ready a person is to manage their own health.
  • PHQ-9: A 9-question depression screening survey.
