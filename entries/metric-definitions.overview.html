Metric definitions

Reference Overview

Business definition

These rules match the cleaned cumulative members master script and the CORE SQL in this repo.

As-of date for Pathway and phases: last day of the latest loaded reporting month (BigQuery). The Colab cumulative script uses the script run date for the pathway window.

Enrollment grain: (member_cin, ecm_enrollment_start_date). Measurements for a CIN are available to each of that CIN's enrollment episodes; selection uses that episode's start date.

Terms used on this page

  • As-of date: The date a rule is measured on. For monthly reporting it is usually the last day of the reporting month.
  • BigQuery: Google's cloud database where the pipeline stores its tables.
  • CIN: Client Index Number: the Medi-Cal member ID. It is PHI. Never type a real one into GitHub.
  • Colab: Google Colaboratory: the browser notebooks in notebooks/ that run the monthly pipeline.
  • CORE: The BigQuery layer where SQL turns raw source data into business meaning (for example enrollment episodes). CORE objects are views.
  • Pathway: How a member's diabetes is tracked: CGM, BGM, or A1c. Based on their devices and recent readings.
