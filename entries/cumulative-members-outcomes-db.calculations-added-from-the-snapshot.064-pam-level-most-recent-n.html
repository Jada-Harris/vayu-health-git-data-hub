064. PAM Level Most Recent N

Metric Calculations added from the snapshot · 064. PAM Level Most Recent N

In plain terms

The member's most recent PAM level as a number (1 to 4). If there is no follow-up survey, it uses the first level instead.

Business definition

Tableau name: PAM Level Most Recent N.

Snapshot position 526 of 600 on this page. Workbook association: Vayu Health Cumulative Members & Outcomes DB.

Approval status: Draft written from the Tableau formula on 2026-11-20, pending review by the data lead.

Check before approving: Because of that fallback, the "most recent PAM level" counts include members who took only one survey. Confirm that is intended.

The same formula text also appears on this page at PAM Level Most Recent N ((Strategic View) Vayu Health Cumulative Members & Outcomes DB; position 245). That is a text match, not proof of one shared calculation or of equal dashboard results.

IF NOT ISNULL([PAM_Level_Baseline])
    AND TRIM(STR([PAM_Level_Most_Recent])) != ""
THEN
    IF CONTAINS(STR([PAM_Level_Most_Recent]), "4") THEN 4
    ELSEIF CONTAINS(STR([PAM_Level_Most_Recent]), "3") THEN 3
    ELSEIF CONTAINS(STR([PAM_Level_Most_Recent]), "2") THEN 2
    ELSEIF CONTAINS(STR([PAM_Level_Most_Recent]), "1") THEN 1
    END
ELSE
    [PAM Level Baseline N]
END

Terms used on this page

  • Baseline: A member's first relevant measurement for an enrollment, picked as the one closest to the enrollment start date. Used to measure change over time.
  • Cumulative Members: The permanent list of every Vayu enrollment episode, kept in MART_Cumulative_Members.
  • PAM: Patient Activation Measure: a 13-question survey (scored 0 to 100, levels 1 to 4) about how ready a person is to manage their own health.
  • Tableau: The dashboard tool Vayu uses for program reporting.
  • View: A saved database query that always shows current data. Unlike a table, it stores no rows of its own.
